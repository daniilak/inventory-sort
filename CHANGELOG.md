# Changelog

## 1.1.0

- улучшено распознавание специализированных и модовых слотов;
- сортировка учитывает предметы с разными data components;
- сортировка стала транзакционной: при невозможности безопасно разложить предметы меню не изменяется;
- исключено выбрасывание предметов при неудачной сортировке;
- кнопки не показываются, если сервер не поддерживает Inventory Sort;
- кнопки сортировки и переноса собраны в одну панель рядом с заголовком контейнера;
- README обновлён для публикации и модпаков.

## 1.0.1

- добавлены кнопки сортировки и переноса для контейнеров.
