# Inventory Sort 1.1.0

Fabric-мод для Minecraft 1.21.1, который добавляет безопасную сортировку инвентаря и перенос предметов в контейнеры.

## Возможности

- сортировка инвентаря по строкам и столбцам;
- сортировка обычных контейнеров по строкам и столбцам;
- перенос предметов из инвентаря в контейнер без хотбара;
- перенос содержимого контейнера обратно в инвентарь;
- компактная панель сортировки и переноса рядом с заголовком контейнера;
- учёт названий, чар, компонентов и другого дополнительного состояния предметов;
- поддержка предметов из модов без отдельного списка совместимости.

Кнопки появляются только когда сервер поддерживает Inventory Sort. Поэтому установка мода только на клиент не отправляет неизвестные пакеты на обычный сервер.

## Совместимость с модами

Предметы сравниваются через `ItemStack.isSameItemSameComponents`, поэтому одинаковые предметы с разными чарами, именами или компонентами не смешиваются.

Обычные модовые сундуки, ящики, бочки и другие универсальные storage-контейнеры работают автоматически. Специализированные слоты машин — результат, броня, топливо, фильтры и т.п. — проверяются отдельно; если слот нельзя безопасно распознать, сортировка отменяется без изменения содержимого.

## Безопасность сортировки

Перед изменением меню мод сначала строит полную раскладку. Если какой-либо предмет нельзя вернуть в выбранный регион, операция отменяется целиком: частичной сортировки, потери или выбрасывания предметов не происходит.

Перенос в контейнер, как и обычное перемещение предметов в Minecraft, может выбросить остаток на землю, если места действительно не хватило.

## Производительность

Сортировка запускается только по нажатию кнопки, а не каждый тик. Число слотов в обычных контейнерах небольшое, поэтому алгоритм работает за ограниченное время даже при предметах из больших модпаков. Слияние учитывает максимальный размер стака и компоненты предмета.

## Установка

Для установки требуются:

- Minecraft 1.21.1;
- Fabric Loader;
- Fabric API;
- Java 21.

Клиентская и серверная установка используют `inventory-sort-1.1.0.jar`. В одиночной игре файл находится в папке `mods` инстанса.

Файл `-sources.jar` содержит исходники и не является установочным модом.

## Сборка

```bat
gradlew.bat build
```

Готовый файл: `build/libs/inventory-sort-1.1.0.jar`.
